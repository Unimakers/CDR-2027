# Coupe de France de Robotique 2027 - Unimaker I1/I2

> [!IMPORTANT]
> Ce repo a été créé depuis le template de projet du MakerSpace d'Amiens.
> Les guides d'utilisation du template sont sur le
> [site de documentation du MakerSpace](https://doc.makerspace-amiens.fr/workshops/methodologie-de-projet/).

Ce repo est un site de documentation réalisé par l'équipe des première et deusième années pré-ingénieur de l'école Unilasalle-Amiens, membre de l'association de robotique Unimaker, dans le cadre de leur participation à la Coupe de France de Robotique 2027 (CDR 2027).
Cette documentation sera mise à jour tout au long de l'année à chaque étape du projet.

- **Documentation :** [site du projet](https://unimakers.fr/CDR-2027/) (sources dans [`docs/`](docs/))
- **Fichiers du projet :** [`project/`](project/) (CAO, électronique, code)
