## Réalisé durant la séance :

### Brainstorm Graal

J'ai pu brainstorm avec Emma sur les différentes manières d'effectuer l'action du Graal, c'est-à-dire de l'élever sur le toit du robot ou sur les murailles du château. Nous avons trouvé plusieurs idées :

| Système | Avantage | Désavantage |
|---------|----------|-------------|
| Ascenseur à courroies | Très maniable | Nécessite au moins un stepper |
| Ascenseur à crémaillère | Facile à mettre en place | Demande un gear ratio élevé sur des servomoteurs ce qui peut les abîmer et tend à dépasser au-dessus |
| Ascenseur à poids | Très facile à mettre en place | Alourdit le robot et ne s'effectue qu'une fois (réinitialisation manuelle) |

Pour l'instant, seuls des systèmes d'ascenseur ont été vus comme possibles pour le robot en impliquant un graal passif. D'autres pistes seront à explorer ultérieurement.

### Code de déplacement absolu PAMI

J'ai créé des fonctions permettant de mettre à jour les coordonnées absolues lors d'un déplacement.

### `update_x`

La fonction `update_x` permet de mettre à jour la coordonnée x en fonction de la coordonnée de départ, l'orientation du PAMI et la distance parcourue. Il s'agit d'une simple fonction mathématique mais qui sera utilisée à chaque déplacement.

```cpp
float update_x(float x, float angleDeg, float distanceMm)
{
    return lround(x + cos(angleDeg)*distanceMm);
}
```

### `update_y`

Même fonction mais pour la coordonnée y, les deux seront en tandem.

```cpp
float update_y(float y, float angleDeg, float distanceMm)
{
    return lround(y + sin(angleDeg)*distanceMm);
}
```

### `updateAngle`

La fonction `updateAngle` permet de mettre à jour l'orientation du PAMI. Elle ne dépend que d'elle-même car l'angle ne modifie pas/peu les coordonnées du PAMI car il tourne sur place.

```cpp
float updateAngle(float starting_angleDeg, float turn_angleDeg)
{
    return lround(starting_angleDeg + turn_angleDeg);
}
```

### `StepToDistance`

L'inverse de `DistanceToStep` qui permet de convertir un nombre de step en distance. Cela permettra de retrouver la distance restante à parcourir en cas d'interruption (car on peut retrouver le nombre de steps à faire).

```cpp
float StepToDistance(float step)
{
    return lround((2*step*wheelCircumferenceMm)/stepsPerWheelRevolution);
}
```

### `setAngle`

La fonction `setAngle` permet de faire tourner le PAMI à une orientation précise et met à jour son orientation.

```cpp
float setAngle(float start_angleDeg, float wanted_angleDeg)
{
    float angle = wanted_angleDeg - start_angleDeg;
    turn(angle);
    return updateAngle(start_angleDeg, angle);
}
```
