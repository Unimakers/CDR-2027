### 4. Cours de gestion de projet : choix techniques pour la Coupe de France de robotique
Pendant le cours de gestion de projet, nous avons défini les choix techniques de notre robot pour la Coupe de France de robotique, en les justifiant avec la méthode FAST.

#### Diagramme FAST

**Fonction principale : jouer un match**

| Fonction de service | Fonction technique | Solution |
|---|---|---|
| **Homologuer** | Respecter les dimensions | Restreint / étendu ? |
| | Vérifier la batterie | La sortir / protection |
| | Choisir la stratégie d'homologation | À définir |
| **Démarrer** | Allumer le robot | À définir |
| | Activer le robot | Tirette |
| **Se déplacer** | Déplacer le robot | À définir |
| | Ne pas toucher l'adversaire | Détection, puis réaction (évitement, arrêt…) |
| **Jouer la mission** | Mettre en place le robot sur la table | Auto ? Manuel ? |
| | Choisir la stratégie du robot | IA ? Automate ? Réactionnaire ? |
| | Interagir avec les cartons | À définir |
| | Amener les blocs aux bonnes zones | À définir |
| **Terminer** | S'arrêter en fin de match | À définir |
| | Éteindre le robot | Action des utilisateurs |

#### Liste d'actions (déroulé d'un match)
1. Amener le robot à l'homologation.
2. Respecter les dimensions (restreint / étendu ?).
3. Vérifier la batterie (la sortir / protection).
4. Allumer le robot.
5. Choisir la stratégie d'homologation.
6. Activer le robot avec la tirette.
7. Le robot se déplace.
8. Le robot ne touche pas l'adversaire (détection, puis réaction : évitement, arrêt…).
9. Mettre le robot en place sur la table de jeu (auto ? manuel ?).
10. Choisir la stratégie du robot (IA ? automate ? réactionnaire ?).
11. Interagir avec les cartons.
12. Amener les blocs dans les bonnes zones.
13. S'arrêter en fin de match.
14. Les utilisateurs éteignent le robot.
