## Spi : buse de com

- SCK : transfer clock
- SDI : input
- SDO : output
- CS : chip select

Chaque element sur le bus à un CS, microcontroleur a flash (stockage) et ram (vive).
On peut ajouter de la psram (augmenter ram).

Quad SPI limite vitesse de com - donc octal SPI (8 lignes de donnés, 11 broches) donc on mange sur Gpio.

Dans module wroom - composant esp32 s3 (on a pas le matos pour souder le composant donc on achete le module [valider par espressif]).
