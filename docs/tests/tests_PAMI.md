## Test 1 : Rotation correcte

### Test 1.1 : Aller-retour

**Critère visé :** <1° de décalage.

**Méthode :** Faire avancer le PAMI de 2m, se retourner (rotation de 180°) puis revenir sur ses pas en notant le décalage entre sa position de départ et sa postion d'arrivé. Répéter environ 25 fois

**Conditions :** Température ambiante, surface de partie (vinyle de table de match).

### Test 1.2 : Précision

**Critère visé :** jusqu'à 1°

**Méthode :** Faire tourner le PAMI d'un nombre de dégrés décroissant jusqu'à une absence de réponse lors d'une rotation. n sera donc la l'angle seuil de réponse.

**Conditions :** Température ambiante, surface de partie (vinyle de table de match).
